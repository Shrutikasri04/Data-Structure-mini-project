This project implements an algorithm that processes student scores from an online examination system. It calculates the average score, sorts the results, and identifies the highest-scoring and lowest-scoring students.

-> Features

Calculates the average score of all students

Sorts student scores in ascending or descending order

Identifies the top-performing student

Identifies the least-scoring student

Simple and efficient logic suitable for academic and beginner projects
